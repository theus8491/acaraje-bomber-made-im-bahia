# Acarajé Bomber Bahia — PWA

Pasta final pronta para publicação.

## Como publicar

Envie todos os arquivos desta pasta para a raiz de um site com HTTPS. Não renomeie nem remova `manifest.webmanifest`, `sw.js` ou `bomberman-bahia-icon.png`.

Abra o endereço no celular usando Chrome, Edge ou Safari e escolha **Adicionar à tela inicial** ou **Instalar app**.

## Arquivos

- `index.html`: jogo otimizado para mobile.
- `manifest.webmanifest`: configuração do aplicativo instalável.
- `sw.js`: cache offline e atualização do PWA.
- `bomberman-bahia-icon.png`: ícone do aplicativo.
