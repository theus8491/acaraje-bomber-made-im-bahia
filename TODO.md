# Entregas

## Site oficial do jogo
- [x] Página inicial em português do Brasil com identidade inspirada em Salvador, comida de rua, cores quentes e energia de arena.
- [x] CTA "Jogar agora" e navegação para o jogo completo.
- [x] Seções explicando a missão, bombas de acarajé, melhorias, supers, mapas, controles e instalação no celular.
- [x] Apresentação dos mapas Pelourinho, Morro + Carro de Som e Feira de São Joaquim.
- [x] Apresentação dos supers Calor, Gelo, Ladrão, Voador e Ninja.
- [x] FAQ responsivo e rodapé com créditos.

## Jogo fornecido
- [x] Código do ZIP mantido no site em `client/public/game/`.
- [x] PWA original preservado com `manifest.webmanifest`, `sw.js` e ícone.
- [x] Rota fullscreen `/game/` para jogar no navegador.
- [x] IA do bot melhorada para evitar autoexplosão: valida caminho de fuga, prioriza saída imediata e replaneja diante de perigo iminente.
- [x] Menu original ampliado com os modos "1 Bot" e "2 Bots", com HUD e posições extras para a partida contra dois bots.
- [x] Os cinco supers ficam expostos na seleção rápida, além do menu de seleção existente.
- [x] D-pad mobile aceita arraste contínuo: o jogador pode deslizar entre direções sem travar em toques individuais.
- [x] Versões separadas por plataforma: `/game/pc` força teclado/sem D-pad e `/game/mobile` força touch com D-pad deslizante; o menu original também permite alternar entre elas.
